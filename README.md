# عقار اليمن – Yemen Real Estate Platform

منصة عقارية إلكترونية احترافية متكاملة تستهدف السوق العقاري اليمني، وتخدم الأفراد، الملاك، السماسرة، والمكاتب العقارية في جميع محافظات الجمهورية اليمنية الـ 22.

---

## 🌟 مميزات المنصة

1. **واجهة عامة احترافية (Premium Real Estate UI):**
   - تصميم عربي عصري متجاوب بنظام اتجاه RTL.
   - هوية بصرية مخصصة (كحلي داكن `#10243A`، أزرق ملكي `#2563EB`، ذهبي هادئ `#C8A96B`).
   - بطاقات عقارات تفاعلية مع معرض صور، وفلاتر بالريال اليمني والدولار والريال السعودي، ووحدات القياس اليمنية (لبنة صنعانية حر، قصبة، م²).
   - دعم الوضع الليلي (Dark Mode).

2. **محرك بحث وتصفية متقدم:**
   - تصفية حسب نوع العملية (بيع / إيجار).
   - تقسيم جغرافي يمني هرمي: **المحافظة ← المديرية ← المنطقة/الحي**.
   - نطاق الأسعار، العملة، عدد الغرف والحمامات، والكلمات المفتاحية.

3. **مساعد عقار اليمن الذكي (Smart Real Estate Assistant):**
   - مساعد تفاعلي يعمل دون الحاجة إلى مفاتيح مدفوعة.
   - يستخرج الطلب تلقائياً (نوع العملية، المحافظة، الحي، نوع العقار، الميزانية) ويبحث داخل قاعدة بيانات MySQL الحقيقية.
   - يعرض بطاقات عقارات تفاعلية مباشرة داخل نافذة المحادثة.
   - معجم مدمج لشرح المصطلحات العقارية اليمنية: (اللبنة الصنعانية، القصبة، المعاد، البصيرة الشرعية، الطابو، الأرض الحر).

4. **نظام مراجعة واعتماد الإعلانات (Publishing Lifecycle):**
   - حالات العقار: `pending` (معلق)، `approved` (معتمد)، `rejected` (مرفوض)، `revision_required` (يحتاج تعديل)، `reserved` (محجوز)، `sold` (تم البيع)، `rented` (تم التأجير)، `suspended` (موقوف).
   - دورة المراجعة الإدارية مع إلزام المدير بكتابة سبب الرفض أو التعديل، مع إشعار المعلن فوراً وإتاحة التعديل وإعادة الإرسال.

5. **لوحة تحكم موحدة للمعلنين (Unified Advertiser Dashboard):**
   - إحصائيات حية ورسوم بيانية بواسطة Chart.js.
   - نموذج إضافة عقار مقسم إلى خطوات (6 خطوات متتابعة).
   - رفع آمن لصور متعددة مع التحقق الصارم من نوع الملف وحجمه (MIME check).
   - إدارة الاستفسارات الواردة، المفضلة، والإشعارات.

6. **لوحة إدارة رئيسية متكاملة (Admin & Super Admin):**
   - إدارة شاملة للعقارات، المستخدمين وتعديل صلاحياتهم (RBAC).
   - إدارة المحافظات والمديريات والمناطق.
   - نظام البلاغات ومكافحة الاحتيال مع إمكانية إيقاف العقارات المخالفة بضغطة زر.
   - سجل العمليات والتدقيق الأمني (Activity Logs).

7. **الأمان والحماية:**
   - استخدام PDO Prepared Statements بالكامل للحماية من SQL Injection.
   - تشفير كلمات المرور باستخدام خوارزمية `password_hash` (BCrypt).
   - حماية كاملة من هجمات CSRF وXSS.
   - حماية رفع الملفات بأسماء عشوائية آمنة ومنع تنفيذ كود PHP داخل مجلد الرفع.
   - حماية ضد هجمات التخمين (Brute Force Protection).

## 💻 متطلبات التشغيل

- **نظام التشغيل:** Windows 10 / 11 أو Linux / macOS.
- **خادم الويب:** Apache (XAMPP).
- **إصدار PHP:** PHP 8.2 أو أحدث (مفعل به امتدادات `pdo_mysql`, `mbstring`, `fileinfo`).
- **قاعدة البيانات:** MySQL 8.0 أو MariaDB 10.4+.

## 🚀 خطوات التثبيت والتشغيل المحلي (Windows & XAMPP)

### الخطوة 1: تشغيل XAMPP
افتح برنامج **XAMPP Control Panel** وتأكد من تشغيل:
- **Apache**
- **MySQL**

### الخطوة 2: تهيئة ملف البيئة `.env`
الملف `.env` جاهز في المجلد الرئيسي بإعدادات XAMPP الافتراضية:
```env
APP_NAME="عقار اليمن"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost/yemen-real-estate/public

DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=yemen_real_estate
DB_USER=root
DB_PASS=
```

### الخطوة 3: تثبيت قاعدة البيانات في خطوة واحدة
يمكنك تثبيت وتهيئة قاعدة البيانات تلقائياً بإحدى الطريقتين:

**الطريقة أ (عبر سطر الأوامر / Terminal في VS Code):**
```bash
php install.php
```

**الطريقة ب (عبر المتصفح):**
افتح الرابط التالي في المتصفح:
`http://localhost/yemen-real-estate/install.php`

سيقوم السكريبت بإنشاء قاعدة البيانات `yemen_real_estate`، استيراد الجداول، وإدراج المحافظات الـ 22 والمديريات والتصنيفات والعقارات النموذجية وحسابات الدخول.

### الخطوة 4: فتح المنصة
افتح المتصفح وتوجه إلى:
`http://localhost/yemen-real-estate/public`
(أو مباشرة عبر خادم PHP المدمج: `php -S localhost:8000 -t public`).

## 📁 هيكل ملفات المشروع

```
yemen-real-estate/
├── app/
│   ├── Config/          # إعدادات التطبيق والاتصال بقاعدة البيانات PDO
│   ├── Controllers/     # وحدات التحكم (Home, Property, Auth, Dashboard, Admin, Chatbot...)
│   ├── Models/          # نماذج قواعد البيانات والعلاقات
│   ├── Middleware/      # حماية الجلسات، الصلاحيات (RBAC)، وCSRF
│   └── Helpers/         # دوال مساعدة للجلسات، التحقق، الرفع الآمن، والقوالب
├── public/
│   ├── index.php        # المتحكم الأمامي وموجه المسارات (Front Controller)
│   ├── .htaccess        # إعادة توجيه الروابط النظيفة
│   ├── assets/          # ملفات التنسيق CSS، الجافاسكريبت، والصور
│   └── uploads/         # مجلدات التخزين الآمنة للصور والوثائق
├── resources/
│   └── views/           # قوالب الواجهات (الموقع العام، لوحة المعلن، لوحة الإدارة)
├── routes/
│   └── web.php          # تعريف كافة مسارات المنصة
├── database/
│   ├── schema.sql       # مخطط قاعدة البيانات MySQL 8 InnoDB utf8mb4
│   └── seed.sql         # بيانات المحافظات، المديريات، والتصنيفات الأولية
├── install.php          # سكريبت التثبيت التلقائي
├── .env.example         # مثال ملف إعدادات البيئة
├── .env                 # ملف إعدادات البيئة المحلي
└── README.md            # هذا الملف التوثيقي
```

## 🌐 النشر على استضافة ويب حقيقية (cPanel / VPS)

1. أنشئ قاعدة بيانات MySQL في لوحة الاستضافة (cPanel MySQL Database Wizard).
2. استورد ملف `database/schema.sql` ثم `database/seed.sql` عبر **phpMyAdmin**.
3. ارفع ملفات المشروع واجعل مسار الدومين يشير إلى مجلد `public/`.
4. حدّث بيانات الاتصال بقاعدة البيانات في ملف `.env`.
5. تأكد من إعطاء صلاحيات الكتابة `0755` لمجلد `public/uploads`.
